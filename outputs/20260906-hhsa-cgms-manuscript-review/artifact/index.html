核心判定

CLAIM NOT ESTABLISHED

較高的 internal CV mean，不等於已證明 superiority。

目前可支持 HHSA 是一種 multiscale、modulation-aware representation；目前不能支持它已具有 statistical superiority、incremental value、clinical usefulness 或 external generalizability。

真實個案適合做 method stress test

可以回答

Representation 是否穩定？

檢查 decomposition、envelope、constraint retention、band edge、surrogate 與 implementation sensitivity。

不能回答

分類器是否更準？

單一 feature vector 沒有跨受試者 labels、paired predictions 或 independent outcomes。

主要 failure modes
01
Band constraints
可能在 feature extraction 前捨棄大量 second-layer amplitude。
02
24 h edge
接近 daily scale 的 mode 可能因數值差異跳入或跳出 band。
03
Method choices
Matched specification 的重現性不能外推為跨 decomposition robustness。
04
Surrogate interpretation
未校正的單一 small p-value 不能證明 nonlinear coupling。
05
Digitized resolution
接近有效解析度下限的 fast band 不能驗證 fast physiology。
03

Reviewer 應要求的分析

Paired uncertainty

保存 OOF probabilities，報告 paired difference、95% CI 與 corrected resampling analysis。

Incremental value

在 nested outer folds 比較 conventional-only、HHSA-only、combined。

Feature accounting

公開公式、單位、selection space、selection stability 與 constraint retention。

External validation

在 independent cohort 預先指定 primary metric、threshold 與 clinical outcome。
