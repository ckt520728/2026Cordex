# 結論

非侵入性腦刺激（non-invasive brain stimulation, NIBS）不是一個可用「有效／無效」二分的單一治療類別。可信的判讀單位是：

> **modality × protocol × target/network × brain state × endpoint × timescale**

rTMS/TBS 能直接誘發神經放電，最適合做具毫秒級時間解析度的 causal perturbation，且在 depression 已有成熟臨床證據。tDCS 主要以 subthreshold polarization 改變神經元對輸入的敏感度，便宜、可重複，但 dose、montage、皮質幾何與 baseline state 使簡單極性規則不可靠。tACS 以週期性電場影響 phase/frequency dynamics，最具「節律特異性」吸引力，但 retinal/cutaneous stimulation、blinding 與 recording artifact 是機制宣稱的核心威脅。跨技術的 cognitive enhancement 多為小效應、task-specific、異質，不能從健康受試者短期 task performance 直接外推疾病的日常功能或 disease modification。

## 一、四種技術改變的不是同一層級

| 技術 | 直接物理作用 | 合理的強主張 | 常見過度主張 |
|---|---|---|---|
| rTMS | suprathreshold magnetic induction；可誘發 action potentials | 時序與區域／network 的 causal perturbation；重複療程的 offline clinical modulation | 把刺激點視為單一功能中心；把 frequency 固定等同 excitatory/inhibitory |
| iTBS/cTBS | 50-Hz triplets 以 5-Hz theta pattern 組織 | protocol-specific plasticity 與 clinical noninferiority（iTBS in MDD） | 把 motor-cortex LTP/LTD-like direction 泛化到所有 prefrontal cognition |
| tDCS | weak direct current；subthreshold polarization | 調整 input-output gain、plasticity context 與 network excitability | 「anode 一定興奮、cathode 一定抑制」；短期 task gain 等同治療 |
| tACS | weak alternating current；phase/frequency-dependent polarization | 在適當 controls 下的 online phase/frequency modulation；可能產生 offline plasticity | 未排除感覺 pathway 或 artifact 就宣稱 direct cortical entrainment |

### 作者整合

「刺激強度較強」不等於「證據較強」；證據強度取決於 experimental contrast、sham fidelity、blinding、target engagement、endpoint validity、replication 與 follow-up。這是 C20 的原創概念模型，不是已驗證的 prognostic score。

## 二、認知神經科學：perturbation 比 enhancement 更成熟

### 1. TMS/TBS

TMS 的價值首先是介入時間窗與 network node，觀察行為或下游神經反應是否改變。這可把「某腦區活動與任務相關」提升為「在特定時間窗擾動此區會改變任務」；但仍不等於該區單獨產生該功能，因為 remote propagation、compensation、state-dependence 與非特異性感覺效應仍存在（C17）。

健康族群的 offline high-frequency rTMS meta-analysis 顯示 accuracy 與 reaction time 的平均效應很小；iTBS cognition meta-analysis 對 outliers、target location 與 navigation method 敏感；prefrontal cTBS 的 direction 亦受 task 與 inhibition of competing processes 影響（C16）。因此，TMS/TBS 對 cognition 的最佳用途是測試可否證的 network hypothesis，而非泛稱「提升腦力」。

### 2. tDCS

人體 intracranial measurements 證明常規電流可在腦內產生可測電場，但 cortical folding 使同一電極下也可能同時出現 inward/outward current。dose-response 也非線性，baseline medication、age、anatomy 與 task state 皆可改變結果（C12）。Working-memory literature 同時存在 small positive meta-analytic signal 與 evidential-value criticism（C16）；這種 tension 必須保留，不能用單一陽性試驗消除。

### 3. tACS

tACS 的關鍵問題不是「刺激後 alpha/gamma 有沒有增加」，而是：

1. 變化是否在刺激期間與外加 phase/frequency 鎖定？
2. 是否排除 retinal/cutaneous afferent entrainment？
3. concurrent EEG/MEG 的 non-linear artifact 是否充分處理？
4. offline after-effect 是否更符合 synaptic plasticity 而非持續 entrainment？
5. neural change 是否伴隨預先指定且具臨床意義的 behavioral endpoint？

Helfrich、Witkowski、Kasten 等研究提供 online interaction 的 mechanistic evidence；Vossen 顯示 after-effect 可更符合 plasticity；Kleinert 的 frequency-unspecific null 與 Schutter 的 sensory-confound review 則限制直接 cortical entrainment 的普遍性（C13–C15）。

## 三、神經精神疾病

### Depression

- **rTMS：** 左 DLPFC high-frequency rTMS 為 IFCN Level A（C01）。
- **iTBS：** THREE-D 支持對標準 10-Hz rTMS 的 noninferiority，主要優勢是 session time，而不是已證明更高 efficacy（C02）。
- **Accelerated iTBS/SNT：** sham-controlled RCT 有快速療效 signal，但 open-label 的極高 remission 數字不可泛化；sample、single-center 與 durability 仍是限制（C03）。
- **tDCS：** ELECT-TDCS 未證明對 escitalopram noninferiority。它可能優於 placebo，但不能據此宣稱可替代 first-line pharmacotherapy（C09）。
- **tACS：** early RCT/meta-analysis signals 存在，但 evidence base 小、protocol 異質，未達 rTMS 的成熟度（C15）。

### Schizophrenia

rTMS 對 auditory hallucinations、negative symptoms 與 cognition 的結果受 target/frequency 與 trial quality 影響；2020 guideline 未將其提升至 Level A/B。tDCS 有 working-memory/neurocognition 的較新陽性 RCT，但必須等待 independent replication、functional outcomes 與 durability（C11）。短期 cognitive score improvement 不能等同 vocational/social recovery。

### OCD

FDA 2018 authorization 是 BrainsWay deep TMS system 的 device/protocol-specific 判定；100 人試驗 active response 38%、sham 11%，但不能寫成「FDA 核准所有 TMS 治 OCD」（C04）。pre-SMA tDCS 有小型 RCT，仍屬 investigational（S15）。

### PTSD

2020 IFCN 對 right-DLPFC high-frequency rTMS 給 Level B；然而 2024 Cochrane review 對當代 pooled evidence 的結論是，active rTMS 對短期 PTSD severity 可能 little-to-no difference，且 sensitivity analysis 呈顯著異質。兩者 evidence window 與問題不同，不能只引用較早 guideline 而省略 contemporary uncertainty（C05）。tDCS/VR 等結合式介入值得研究，但無法拆解電刺激與 exposure components 時，mechanistic attribution 必須保守。

### Addiction

multicenter RCT 顯示 lateral prefrontal/insular deep rTMS 加 cue provocation 可提高 tobacco abstinence（C06）。此結果不能泛化到所有 substances、一般 DLPFC coil 或不含 cue-provocation 的 protocol。

### MCI/Alzheimer's disease

precuneus rTMS phase-2 RCT（n=50）在 24 週顯示 CDR-SB 與 secondary cognitive/functional outcomes 的 signal；這是 promising，而非 routine-care evidence（C07）。component network meta-analysis 與 gamma tACS studies 提供可研究的方向，但 modality、stage、outcome 與 follow-up 異質；biomarker、perfusion 或 oscillatory change 不能等同 disease modification（C08）。

## 四、安全性

- TMS：常見 scalp discomfort/headache；seizure 是嚴重但罕見風險。不能用一個 universal rate 涵蓋不同 coil、frequency、intensity、medication 與族群。implant、seizure risk、medication、sleep deprivation 等需依 current guideline screen（C19）。
- tES：2026 guideline 在逾 300,000 sessions 中未報告 tES-related serious adverse events；其主要安全範圍為 ≤4 mA、≤60 min/day。常見的是與刺激時間相關的 tingling/burning、headache、fatigue 等 adverse events，但 temporally associated AE 不等同已確立因果的 side effect；更高 dose、監測品質與 under-reporting 仍是限制。這支持 guideline-defined dose 的 safety profile，不代表 efficacy，也不支持 DIY（C18）。

## 五、Evidence certainty matrix

| 應用 | rTMS/TBS | tDCS | tACS | 臨床解讀 |
|---|---|---|---|---|
| MDD/TRD | 高 | 中 | 低—中 | rTMS/iTBS 最成熟 |
| OCD | 中（device-specific） | 低 | 很低 | dTMS 有 regulatory evidence |
| PTSD | 中 | 低 | 很低 | protocol 尚未標準化 |
| Tobacco use disorder | 中（device/protocol-specific） | 低—中 | 很低 | 不能泛化其他 addiction |
| Schizophrenia cognition/symptoms | 低—中 | 低—中 | 低 | promising，尚不一致 |
| MCI/AD cognition | 低—中 | 低—中 | 低—中 | investigational；需大型、多中心、長期 RCT |
| Healthy cognitive enhancement | 小效應、高異質 | 小效應、可重複性爭議 | 小效應、confounds 顯著 | 不支持 consumer「brain boosting」宣傳 |

## 六、Research agenda

1. 以 electric-field/network engagement 而非 scalp coordinate 報告 dose。
2. 預先指定 primary endpoint、minimal clinically important difference 與 durability。
3. 同時報告 nulls、adverse effects、blinding guess 與 sensory intensity。
4. tACS 使用 active sensory controls、retinal controls 與 artifact-aware concurrent recording。
5. TMS/TBS 以 individualized network target 與 state-triggered protocols 測試，但先以 preregistered head-to-head RCT 證明增益。
6. MCI/AD 試驗分層 disease stage、biomarker status、atrophy/field modeling，並把 cognition、function 與 biomarker 分開。
7. 將跨 modality 比較建模為完整 intervention package，而非只用技術名稱。

## Evidence-bound conclusion

現階段最穩健的臨床結論是：rTMS/iTBS 對 MDD/TRD 已具成熟、protocol-specific evidence；OCD 與 tobacco use disorder 有 device-specific regulatory/RCT support；其餘 neuropsychiatric 與 neurodegenerative applications 多屬 promising but investigational。認知神經科學上，NIBS 對 causal perturbation 的價值高於對普遍 cognitive enhancement 的證據。任何「腦波同步」「plasticity」或短期 task gain，都必須經過 mechanism、sensory confound、endpoint 與 timescale 四重檢查，才可能轉譯成臨床主張。
